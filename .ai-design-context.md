# DESIGN CONTEXT

[LLM-CONTEXT-START]
[SECTION:STYLING-ANATOMIE]
- Toolkit: Tailwind CSS + Native CSS Custom Properties.
- Primitives: Fluid Type System, Grid-System.
- Tokens: 3-Tier System (Primitives wie `--color-primary-500`, Semantics wie `--background`, Components wie `--card-bg`).
- Motion: Reduziert verfuegbar, Prefers-Reduced-Motion implementiert.
[/SECTION]

[SECTION:ACCESSIBILITY-BASELINE]
- Semantik: Korrekter Einsatz von HTML5 Tags (`main`, `nav`, `section`). Keine Div-Suppen.
- Tastatur-Navigation: Exzellentes Focus-Management via Global CSS (`*:focus-visible` offset).
- Kontraste: AA/AAA Compliance aus the Box. Kein Dark Mode.
[/SECTION]
[LLM-CONTEXT-END]
