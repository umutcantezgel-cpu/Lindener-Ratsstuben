# 📖 Bedienungsanleitung: Lindener Ratsstuben Speisekarte (CMS)

Herzlich willkommen! Mit diesem System können Sie die Speisekarte Ihrer Webseite (www.lindener-ratsstuben.de) jederzeit selbstständig, schnell und unkompliziert anpassen. 

Egal ob Sie Preise ändern, neue Gerichte hinzufügen oder Tippfehler korrigieren möchten – alle Änderungen sind nach dem Speichern innerhalb von Sekunden auf Ihrer Webseite sichtbar!

---

## 1. Wie logge ich mich ein?

1. Öffnen Sie in Ihrem Browser (z.B. Chrome oder Safari) folgende Adresse:
   👉 **[www.lindener-ratsstuben.de/sanity](https://www.lindener-ratsstuben.de/sanity)**
2. Loggen Sie sich mit dem Konto ein, das für Sie eingerichtet wurde (z.B. Ihr Google-Konto oder Ihre E-Mail-Adresse).

---

## 2. Die Übersicht verstehen

Nach dem Einloggen sehen Sie auf der linken Seite das Hauptmenü:

*   **⚙️ Einstellungen:** Hier könnten in Zukunft globale Dinge wie Öffnungszeiten stehen.
*   **🍽️ Speisekarte:** **Das ist Ihr Haupt-Arbeitsbereich!** Hier finden Sie alle Gerichte.
*   **📅 Reservierungen:** (Falls aktiviert) Übersicht der Anfragen.

### Gerichte nach Kategorie finden
Klicken Sie auf **🍽️ Speisekarte** und dann auf **📂 Gerichte nach Kategorie**. 
Sie sehen nun eine übersichtliche Liste all Ihrer Speisekarten-Kategorien (z.B. *🍕 Pizza, 🍝 Pasta, 🥗 Salate*).
Klicken Sie auf eine Kategorie, um alle darin enthaltenen Gerichte zu sehen.

---

## 3. Einen Preis oder Text ändern

1. Navigieren Sie zu dem Gericht, das Sie ändern möchten (z.B. über "Gerichte nach Kategorie" -> "Pizza" -> "Margherita").
2. Klicken Sie auf das Gericht. Auf der rechten Seite öffnet sich nun das Bearbeitungsfenster.
3. Ändern Sie einfach den Text in dem entsprechenden Feld:
    *   **Name:** (z.B. "Pizza Margherita")
    *   **Beschreibung:** (Die Zutaten, z.B. "mit Tomatensauce und Käse")
    *   **Preis:** Tragen Sie hier den neuen Preis als Zahl ein (z.B. `8.50`). *Wichtig: Bitte einen Punkt statt Komma verwenden!*
4. **Das war's!** Unten rechts sehen Sie einen grünen Button mit der Aufschrift **"Publish"** (Veröffentlichen). Sobald Sie darauf klicken, ist die Änderung live auf der Webseite!

---

## 4. Ein neues Gericht hinzufügen

1. Klicken Sie oben in der Mitte der Übersicht auf das **Stift-Symbol (📝)** oder wählen Sie in der linken Spalte oben den Button zum Erstellen eines neuen Eintrags.
2. Wählen Sie als Typ **"Gericht"** (Dish) aus.
3. Füllen Sie die Felder aus:
    *   Geben Sie einen **Namen**, eine **Beschreibung** und den **Preis** ein.
    *   Wählen Sie unter **Kategorie** die passende Gruppe aus (z.B. "Pizza").
    *   *(Optional)* Fügen Sie Allergene hinzu, falls gewünscht.
    *   *(Optional)* Sie können auch ein Foto des Gerichts hochladen!
4. Wenn alles passt, klicken Sie unten rechts auf **"Publish"**. Das neue Gericht erscheint sofort auf der Webseite in der richtigen Kategorie.

---

## 5. Ein Gericht von der Karte nehmen (Entfernen)

Gibt es ein Gericht aktuell nicht mehr? Sie haben zwei Möglichkeiten:

**Möglichkeit A: Verstecken (Empfohlen!)**
Anstatt das Gericht komplett zu löschen, können Sie es einfach "verstecken".
Ganz unten in der Bearbeitungsansicht eines Gerichts finden Sie oft einen Schalter wie *"Sichtbar"* oder *"Verfügbar"*. Falls Sie das Gericht vorübergehend von der Karte nehmen wollen, deaktivieren Sie es hier einfach. (Klicken Sie danach wieder auf "Publish").

**Möglichkeit B: Komplett Löschen**
Wenn das Gericht für immer von der Karte verschwinden soll:
1. Klicken Sie auf das Gericht, sodass es rechts geöffnet ist.
2. Klicken Sie ganz unten rechts neben dem grünen "Publish"-Button auf die **drei kleinen Punkte (...)**.
3. Wählen Sie **"Delete"** (Löschen) aus.
4. Bestätigen Sie, dass Sie das Gericht wirklich löschen wollen. Es verschwindet sofort von der Webseite.

---

## 💡 Häufige Fragen & Tipps

*   **Hilfe, ich habe etwas Falsches gelöscht!** Keine Panik. Sanity merkt sich Änderungen. Sie können über die drei Punkte (...) rechts unten oft eine ältere Version wiederherstellen ("Revert").
*   **Warum sehe ich meine Änderung auf dem Handy nicht?** Manchmal speichert Ihr Handy alte Webseiten ab (Cache). Laden Sie die Seite auf dem Handy neu oder warten Sie ein paar Minuten.
*   **Zahlenformat beim Preis:** Bitte denken Sie daran, bei Beträgen mit Cent einen **Punkt** anstelle eines Kommas zu nutzen (Richtig: `12.50` | Falsch: `12,50`). Das System fügt das €-Zeichen automatisch auf der Webseite hinzu!
