# Anleitung zur Nutzung der Mittagsmenü-Word-Vorlage

Diese Microsoft Word Vorlage (`Mittagsmenue_Vorlage.docx`) wurde speziell erstellt, um Ihnen die volle Kontrolle über Ihr wöchentliches Mittagsmenü zu geben. Das Layout, die Farben und die Typografie wurden so konfiguriert, dass sie exakt Ihrem hochwertigen Markenauftritt (Corporate Identity) entsprechen.

## 1. Voraussetzungen: Schriftarten installieren
Damit die Vorlage korrekt angezeigt wird, müssen die folgenden Schriftarten auf Ihrem Computer installiert sein:
- **Cinzel** (Für Überschriften)
- **Cormorant** (Für Beschreibungen)
- **Montserrat** (Für Fließtext und Preise)

*Hinweis: Wenn diese Schriftarten nicht installiert sind, wird Word sie durch Standard-Schriftarten (wie Arial oder Times New Roman) ersetzen, was das Design beeinträchtigt.*

## 2. Bearbeiten der Vorlage
Wir haben in Word spezielle "Formatvorlagen" (Styles) für Sie angelegt. Sie müssen sich keine Gedanken über Schriftgrößen oder Farben machen.

1. Öffnen Sie die Datei `Mittagsmenue_Vorlage.docx` in Microsoft Word.
2. Markieren Sie den Text, den Sie ändern möchten (z. B. "Tomatensuppe").
3. Tippen Sie Ihr neues Gericht ein.
4. **Formatierung beibehalten:** Das Dokument nutzt vordefinierte Formatvorlagen.
   - **Kategorie Überschrift:** Für Kategorien wie "VORSPEISEN" oder "HAUPTSPEISEN" (Gold, Cinzel).
   - **Gericht Titel:** Für den Namen des Gerichts (Rot, Cinzel).
   - **Gericht Beschreibung:** Für die Zutaten (Schwarz, kursiv, Cormorant).
   - **Preis:** Für die Preise rechts (Rot, Montserrat).

*Tipp: Wenn Sie einen neuen Eintrag erstellen möchten, kopieren Sie am besten einen bestehenden Block (Titel, Beschreibung, Preis) und fügen ihn an der gewünschten Stelle ein. So bleibt das Format perfekt erhalten.*

## 3. Speichern und für den Druck exportieren
Wenn Sie Ihr wöchentliches Menü fertiggestellt haben:
1. Speichern Sie das Dokument zunächst ganz normal ab (`Datei > Speichern`).
2. **Wichtig für den Druck & Webseite:** Exportieren Sie das Dokument immer als PDF.
   - Gehen Sie auf `Datei > Exportieren > PDF/XPS-Dokument erstellen`.
   - Speichern Sie es z. B. als `Mittagsmenue_Woche_42.pdf`.
3. Sie können diese PDF nun ausdrucken, per E-Mail an Kunden schicken oder auf Social Media teilen.

## 4. Sicherungskopie
Wir empfehlen, die Datei `Mittagsmenue_Vorlage.docx` als "Schreibgeschützt" zu markieren oder sie an einem sicheren Ort aufzubewahren und für jede neue Woche "Speichern unter..." zu verwenden. So haben Sie immer eine unbeschädigte Originalvorlage zur Hand.
